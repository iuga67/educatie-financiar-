Educație financiară

Aplicația „Educație financiară” îi ajută pe elevi să învețe cum să își gestioneze banii, să economisească și să își organizeze bugetul.

Pentru cine este și cum se folosește?

Aplicația este destinată elevilor, în special celor din clasa a XI-a. Utilizatorii pot parcurge lecții financiare, pot calcula bugetul personal și pot răspunde la întrebările din quiz pentru a-și testa cunoștințele.
